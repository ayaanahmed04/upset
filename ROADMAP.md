# UPSET Roadmap

UPSET is an advanced UFC analytics and machine learning platform focused on
fighter analysis, advanced performance metrics, matchup intelligence, and
interpretable fight predictions.

## Phase 0 — Foundation

- [x] Create GitHub repository
- [x] Configure GitHub authentication
- [x] Configure local development environment
- [x] Install Python 3.12
- [x] Create project virtual environment
- [x] Configure `.gitignore`
- [x] Create initial project structure
- [x] Research and select UFC data sources
- [x] Establish Python dependencies and development tooling

## Phase 1 — Data Foundation

- Collect historical UFC fighter and fight data
- Design the core data model
- Build a reproducible data ingestion pipeline
- Clean and validate raw fight data
- Perform exploratory data analysis

## Phase 2 — Advanced Analytics

Develop interpretable fighter metrics such as:

- Power
- Durability
- Cardio
- Striking efficiency
- Wrestling effectiveness
- Submission threat
- Strength of schedule
- Recent form
- Upset potential

## Phase 3 — Machine Learning

- Build a simple baseline model
- Engineer time-aware fighter features
- Prevent future-information data leakage
- Compare multiple models
- Evaluate predictive performance
- Evaluate probability calibration
- Add model explainability

## Phase 4 — Product

- Build the UPSET API
- Build the web application
- Add fighter profiles
- Add matchup comparison
- Add upcoming fight analysis
- Deploy the application publicly

## Phase 5 — Expansion

Potential future areas:

- Additional MMA promotions
- Betting-market analytics
- Mobile application
- Other combat sports
- Other sports
