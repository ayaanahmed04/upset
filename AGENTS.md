# UPSET release and file safety

- Preserve the user's files and other chats' work. Do not delete, move, reset,
  or overwrite existing source material, portraits, review packages, or
  snapshots without explicit authorization. Before a requested replacement,
  keep a versioned backup of the old files and record the restore path.
- Treat a serving release as a set. The database, reviewed identity archive,
  overall rating snapshot, striking snapshot, and roster must agree. Inspect
  the actual local process and the launcher before changing either. Create
  new database and model artifacts in new directories. Preserve their bound
  sources and manifests so older releases remain reproducible.
- Test the normal launcher on a temporary local port before replacing the
  live viewer. Check a real profile and comparison, a later date with no new
  bouts, an earlier cutoff, portrait delivery, and current fighter search and
  history. A newer date alone must not blank a verified complete snapshot.
  Keep a way to restart the previous verified release.
- Reconcile both participants and both stats rows for every newly reviewed
  bout. Keep source identity candidates separate until reviewed and expose
  pending coverage. Check dated UFC evidence before resolving name collisions
  or adding source histories. Preserve historical dates and original results.
- Reuse the transactional portrait importer with the registry that matches
  the serving database. Verify every imported file and preserve prior roster
  entries. Keep unresolved artwork and flag it for review.

The current local launch, recovery, and portrait refresh instructions are in
`docs/RECOVERY_2026_11_06.md`.
