# UPSET Experimental v3 upper grade revision

Declared November 5, 2026 after the first v3 candidate placed only six of 701
recently competing fighters at 95 or above. That candidate fell short of the
declared 1% minimum and remains archived as a failed candidate.

Limit the revision to the crowded 95–99 range. Reproduce the exact v2 raw
boundaries for grades 90 through 95 using its saved empirical reference and
half-up conversion. Start the spread at the unchanged grade-95 boundary and
keep the first candidate's 99 benchmark. Divide the interval into four equal
bands for 95 through 98, with 99 beginning at the benchmark. Keep the same
display protections and verify every model grade below 95 matches v2. This
preserves the existing entry into the 95 tier and gives the grades within it
room to separate. Apply all original v3 gates without changes. This second
candidate uses the same inspected development evidence as the first.

The first candidate's era diagnostic remains an offline comparison. A new
reference for Elo would change the underlying model, so the live experiment
uses the v2 résumé and skills throughout.
