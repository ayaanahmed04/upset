# UPSET rating interface — November 4, 2026

The local broadcast site now places a compact octagonal UPSET badge beside the
fighter portrait on individual profiles and on both sides of a comparison.
Clicking the badge opens the breakdown in a dialog. No large rating section is
inserted into the normal page.

The number uses the existing Black Ops One stencil font, with UPSET's grunge
texture and a bold fallback. The user-selected color tiers are consistent on
profiles, comparisons and sample component scores:

| Overall / component range | Color |
| --- | --- |
| 90–99 | Red |
| 80–89 | Orange |
| 70–79 | Yellow |
| 60–69 | Blue |

Unrated fighters use a neutral dash. Provisional sample badges are dashed;
the threshold is fewer than four recorded UFC fights. Debut examples have no
assigned score. The original PDF's circular outline and neutral-white matchup
color were superseded by the user's later octagon and tier-color instructions.

## What is working

- Compact badge placement on actual fighter and comparison pages.
- Keyboard-operable badge, accessible dialog, close button and native Escape
  dismissal. Closing returns the viewer to the ordinary page.
- Four-part sample breakdown, component bars, selectable sample raw inputs and
  division percentiles, last-fight changes, history and peak.
- A method panel showing the proposed skills/résumé weights and illustrative
  curve, with an explicit unestablished prediction track record.
- Actual fighter dialogs show the current recorded statistics, their selected
  measurement window and date, alongside plain descriptions of the proposed
  parts. Missing raw values stay unavailable.

Try the compact fictional examples at
<http://127.0.0.1:8768/#/rating-preview>. Both profile and head-to-head examples
use the same badge and dialog component as the live pages. Scores, histories,
percentiles and curve examples are conspicuously labelled fictional.

## Rating engine remains separate work

No actual fighter has been given an invented 60–99 score. The API now includes
an explicit `rating` readiness object with `status=not_available`, null score
and version, the exclusive cutoff, full pre-cutoff fight count and provisional
flag. The badge opens a truthful development explanation until a verified
four-part snapshot exists. The old historical 1500-scale Elo and current
experimental striking percentage are not treated as this overall rating.

The design spec's remaining model requirements include current chronological
résumé, opponent-adjusted and division-relative skill components, declared
exposure/recency handling, chronologically chosen weights, a versioned display
curve, dated snapshots/history and measured later-fight performance. A fitted
rating `ratings.jsonl` has not been generated by this interface work. The
display curve must not be used as a historical machine-learning feature.

The protected defense research, striking preview and serving database remain
unchanged. Existing raw stats and the front-page matchup remain available.
There was no external deployment.

90/99, matchup consistency, modal open/close, no invented real scores and
unchanged sample inputs. Ruff and whitespace checks pass. A later restricted

horizontal overflow. Final screenshots are in
