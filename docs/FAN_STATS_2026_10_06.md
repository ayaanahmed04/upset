## Definitions

All measures use accepted UFC bouts strictly before the exclusive cutoff.
Career uses all available fights; L3/L5/L10 select each fighter's newest N
available bouts. Missing/unlinked fights remain excluded, not zero-filled.

- Knockdown efficiency: 100 × total recorded knockdowns / total significant
  strikes landed in the window. Display counts, not just the ratio. Zero
  strikes means unavailable, not zero efficiency. This is not punch force.
- Knockdowns received: sum the opponent's knockdowns. A count of knockdowns,
  not the number of fights in which the fighter was knocked down.
- KO/TKO losses: reviewed losses grouped as KO/TKO, including doctor
  stoppages under the existing method classifier. Show total losses and
  window bouts. Draws/NC and disqualifications do not count as KO/TKO losses.
- These count measures include bouts with a zero recorded clock. Unlike
  per-minute rates, their denominator does not require fight duration.
- Common opponents: intersect permanent opponent IDs across each fighter's
  selected window. Keep every meeting, including rematches, draws/NC and
  reviewed amendments. No names-only matching or transitive win prediction.
  Show six opponents initially, with a button for all others. Phone layout
  keeps the opponent name above two side-by-side result lists.

New API fields are additive: metrics.power_durability and, on /api/compare,
common_opponents. Existing per-minute rates and percentile inputs stay intact.
An old API paired with the new HTML displays a restart note for these sections.

## Title metadata correction requested during this work

The screenshot and real saved SQLite both show Chimaev's May 9 Strickland
loss. Its current canonical Cito weight_class is only Middleweight. The site
previously counted Title in that string, so it missed the championship status.
The other UFC 328 title bout, Van–Taira, likewise contains only Flyweight.

reviewed_bout_metadata.py adds two evidence-backed research overlays keyed by
provider/bout ID with exact expected date, participant UUIDs and division.
They apply to either participant's report and keep the raw/frozen rows intact.
The official UFC 328 scorecards and results identify both championship bouts:

https://www.ufc.com/news/ufc-328-official-scorecards-chimaev-vs-strickland-judges
https://www.ufc.com/news/ufc-328-chimaev-vs-strickland-results-highlights-main-card-winners-interviews-newark

The history title tag and header counter both use the reviewed evidence;
Data provenance links to its source. Five rounds alone never means a title
fight. This is a correction of these two confirmed bouts, not a comprehensive
audit of all title metadata. The header tooltip notes possible undercounting.
Like result amendments, title evidence is currently reviewed metadata, not
historical knowledge reconstructed as of each date.
