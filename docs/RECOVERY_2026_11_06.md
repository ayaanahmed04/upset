## Refresh pictures from a folder

Keep adding PNGs to the `AUpsetImages` folder already on the Desktop. To
import it and start the site, stop the existing viewer, then run:

```zsh
cd ~/Projects/upset
UPSET_PORTRAIT_SOURCE="$HOME/Desktop/AUpsetImages" ./Start\ UPSET.command
```

Known filenames sync when you run this command. The importer validates PNGs,
retains new files, and lists any filename that still needs a reviewed fighter
ID. It keeps older pictures outside the supplied collection and takes a
backup before a replacement. The folder can also be inside an existing local
cloud sync location if its files are downloaded to this Mac. The launcher
reads the folder at startup.
